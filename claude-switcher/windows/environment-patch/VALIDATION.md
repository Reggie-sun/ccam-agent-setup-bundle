# Validation Status

## Verified

- `dns-patch.js` 使用 Node 执行的配置转换回归：保留原节点、路由和 TUN；重复应用幂等；国内/海外 DNS 策略分离；保留私有 DNS；未知自定义策略拒绝修改；代理组参数不会被解析成另一组。
- 生成的配置已通过真实 Mihomo `v1.19.21` 的 `-t` 校验，包含中文代理组名。
- PowerShell `7.6.9` Linux：AST 解析、无副作用导入，以及隔离临时目录中的安装/重复安装/精确字节恢复/原不存在脚本恢复/自定义脚本拒绝/后续用户改动冲突/时区权限失败回滚/控制接口与组名边界测试。
- 时区函数在隔离测试中使用替身，没有借此修改测试主机的系统时区。
- Chrome 策略名称、值和支持范围已核对 Chromium 官方定义。注册表事务测试使用隔离替身；Linux 无法运行真实 Windows 注册表和 Chrome 管理策略。
- VPS 时区使用固定只读 SSH 命令，离线映射来自固定版本的 CLDR。隔离测试覆盖 UTC、美国时区和 IANA 别名、SSH 参数校验、失败和未知输出拒绝、安装时重新读取以及原时区恢复。测试未连接实际 VPS。
- 发布 ZIP 使用显式文件白名单，附文件 SHA256 和上游 LICENSE。

## Required On Windows

- Windows 10/11 + Windows PowerShell 5.1 下的实际 WPF 界面、中文路径和桌面启动。
- Windows 本机权限下的时区设置、文件替换、失败回滚和恢复。
- Clash Verge Rev 实际加载全局扩展，订阅重新应用后的 DNS 上游日志、客户浏览器与日常业务流程。
- Chrome 策略在 `chrome://policy` 的实际加载、机器策略优先级、重启后的中文界面，以及网页语言/WebRTC/定位/DNS 的真实行为。
- 当前客户配置自定义项与原状态恢复验收。
- Windows OpenSSH 对客户 VPS 的实际密钥登录、主机身份、读取与超时，以及该 Windows 版本的时区 ID 支持。

不要把“写入成功”“DNS 返回响应”或此测试记录当作客户机器的防泄漏、账号可用性或商业验收证明。
